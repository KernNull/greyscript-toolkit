## Project Overview

This repository is the central documentation and development hub for the PINGTOWER Grey Hack campaign.

It records game mechanics, GreyScript language references, campaign progression, network discoveries, programs, exploits, credentials, and experimental scripts.

The goal is to build a reliable, organized reference that supports both gameplay and the development of a reusable Grey Hack scripting arsenal.

All credentials and account details documented here must be fictional, in-game information only.

## Source Classification

Information should be classified so that documented mechanics are not confused with assumptions.

| Classification | Meaning |
|---|---|
| **Manual-sourced** | Directly described in user-provided Grey Hack manual material |
| **External-source** | Retrieved from external documentation or community resources |
| **Game-tested** | Behavior personally verified in the game |
| **Unverified** | Hypothesis, assumption, or behavior awaiting testing |

The GreyScript documentation website is an **unofficial external reference**. It should not be represented as official game documentation.

When sources disagree, preserve the distinction and record the discrepancy rather than silently choosing one version.

## Documentation Governance

This repository uses an owner-controlled approval process.

AI assistants and other contributors may:

- Draft documentation
- Edit proposed changes
- Review technical accuracy
- Identify inconsistencies
- Suggest improvements
- Prepare change records

They may not independently approve a baseline, designate a revision as owner-approved, or override an existing approval.
