# Grey Hack Scripts

Hey! This is my personal collection of **GreyScript** utilities and experiments for the video game **Grey Hack**.

I'm building these scripts as I play and learn the game, and I'm sharing them publicly in case they help anyone else out. **Feel free to copy, fork, tweak, and change these scripts to your heart's content!**

---

## Available Scripts

| Script | Description | Status | Guide |
|---|---|---|---|
| **pingscout** | Read-only network, router, firewall, and LAN reconnaissance tool | `V5` — Stable (Game-Tested) | [pingscout README](GreyHack%20Scripts/pingscout/README.md) |
| **libscan** | Parameterized `metaxploit.so` vulnerability scanner & overflow runner | `V3` — Game-Tested (Read-Only Parser) | [libscan README](GreyHack%20Scripts/libscan/README.md) |
| **localscan** | Local `.so` library scanner & privilege-escalation helper | `V1` — Game-Tested (Read-Only Scanner) | [localscan README](GreyHack%20Scripts/localscan/README.md) |
| **tracecheck** | Read-only active-session (`dsession`) & log awareness utility | `V1` — Game-Tested / `V2` Draft | [tracecheck README](GreyHack%20Scripts/tracecheck/README.md) |

Each script folder includes a plain-English `README.md`, a `Changelog.md`, and a `Drafts/` folder showing how the script evolved.
